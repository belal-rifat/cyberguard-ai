Technique: OS Credential Dumping (MITRE ATT&CK T1003)

Definition:
Credential dumping is a technique where an attacker extracts account login and password information, usually in the form of a hash or cleartext password, from the operating system or software. Once obtained, these credentials can be used for lateral movement or privilege escalation.

Common indicators:
- Unusual access to LSASS process memory (Windows)
- Use of tools such as Mimikatz, ProcDump, or similar credential extraction utilities
- Suspicious registry access related to SAM (Security Account Manager)
- Unexpected creation of memory dump files
- Abnormal access patterns to /etc/shadow on Linux systems

Sub-techniques:
- LSASS Memory (T1003.001)
- Security Account Manager / SAM (T1003.002)
- NTDS (T1003.003): targets Active Directory credential database
- /etc/passwd and /etc/shadow (T1003.008): Linux credential files

Why it is dangerous:
Once credentials are dumped, attackers can move laterally across a network, impersonate legitimate users, and escalate privileges without triggering typical malware alerts, since they are using valid account credentials.

Recommended mitigation:
- Enable Credential Guard on Windows systems
- Restrict and monitor access to LSASS process
- Use strong password hashing algorithms and disable legacy protocols (e.g., NTLM where possible)
- Implement least-privilege access controls
- Monitor for known credential dumping tool signatures with EDR/SIEM
- Rotate credentials regularly and enforce MFA
